# 沖繩本島 Trip Plan（清明連假 5 日／4 人）

**建議日期：** 2027/4/3（六）→ 4/7（三）  
**官方連假：** 2027/4/3–4/6（4 天）；五日遊請 **4/7 一天**（請 1 休 5）  
**出發地假設：** 台北 TPE／TSA → 那霸 OKA  
**人數：** 4 大人＋行李箱  
**重點：** 漁市場多次、租車動線優化、開支估算  

> 價格皆為 **估計區間**（連假會漲）。訂票前請再查一次即時價。匯率約 **¥100 ≈ NT$22**（浮動）。

## 五日動線（車程約估）

### Day 1｜4/3（六）那霸：雙漁市開場
1. 抵達 OKA → 領 **7–8 人座廂型車／ワゴン**（見租車章）  
2. 行李丟那霸飯店（或先放車）  
3. **泊いゆまち**（漁 #1）— 鮪魚丼、逛攤、可看解體室  
4. 國際通散步、壺屋燒物  
5. **牧志公設市場**（漁 #2）— 1F 買魚肉 → 2F 調理「持ち上げ」晚餐  
6. 住那霸  

**車：** 機場→泊港約 15–20 分；泊→國際通約 10 分。牧志附近停車難，建議停 Times 再走路。

### Day 2｜4/4（日）南→北：糸満海鮮 → 西海岸北上
1. 退房  
2. **糸満お魚センター**（漁 #3，道の駅いとまん內）— DIY 海鮮丼  
3. （選）平和祈念公園／南部  
4. 北上國道 58／高速 → **萬座毛**（短停＋三矢ドーナツ）  
5. （選）おんなの駅／御菓子御殿  
6. 入住 **本部 or 名護**（3 晚）  

**車：** 糸満→萬座毛約 70–90 分；萬座毛→本部約 40–50 分。  
**高速：** 建議那覇 IC→許田 IC（普通車 ETC 約 ¥1,040／片道）。

### Day 3｜4/5（一・清明）本部半島：美ら海日
1. **沖縄美ら海水族館**（大人 ¥2,180）— 連假早到或線上票  
2. 園內 **Emerald Beach**  
3. 下午 **瀬底島** 沙灘／繞島  
4. 晚餐本部／名護（ステーキ or 沖繩料理）  
5. 續住北部  

**車：** 美ら海↔瀬底橋約 15–20 分，幾乎無回頭。

### Day 4｜4/6（二）名護漁港＋古宇利
1. **名護漁港水産物直販所**（漁 #4）— 定食／天婦羅（11:00 開）  
2. **古宇利島**（古宇利大橋、愛心岩、海景）  
3. （選）今帰仁城跡／道の駅許田買美ら海優惠票（若隔天還要）  
4. 北部輕鬆晚／泡盛  
5. 續住北部  

### Day 5｜4/7（三）南下還車起飛
1. 退房 → 高速南下  
2. （選）**北谷 American Village** 午餐／伴手  
3. （加碼漁 #5）時間夠再衝 **牧志** 或 **泊いゆまち** 買真空鮪魚伴手  
4. 還車 OKA → 班機回台  

**車：** 本部→那霸機場約 90–120 分（連假塞車預留 2.5–3 小時）。  
**還車：** 至少起飛前 **2.5–3 小時** 到機場（國際線＋還車＋安檢）。

## 租車（4 人＋行李）

### 車型結論
- **不要** 軽自動車／小車：4 大行李箱塞不下。  
- **要** **7–8 人座ミニバン／ワゴン**（Serena、Noah、Voxy、Stepwgn 等）。  
- 用法：3 排座收起 → 後廂放 4 行李箱；4 人坐前兩排。

### 費用估計（那霸機場取還、約 4 日）

| 項目 | 估計 |
|------|------|
| 廂型車連假日租（含基本保險） | ¥12,000–28,000／日 → **¥48,000–110,000／4 日** |
| 免責補償 CDW＋NOC | 約 ¥1,500–2,200／日 → **¥6,000–9,000** |
| ETC 卡租借（若無） | 日租數百～約千円 |
| 高速那覇↔許田 | ETC 約 **¥1,040**／片道（現金約 ¥1,610）→ 行程 **¥2,000–6,000** |
| 汽油（約 500–700 km，ワゴン） | **¥7,000–14,000**（還車滿油） |
| 停車（美ら海／國際通／景點） | **¥2,000–5,000** |
| **租車相關合計** | **約 ¥65,000–140,000（NT$13,000–28,000）** |

### 動線優化原則
1. **住 2 點就好**（那霸 1＋北部 3）— 少搬行李。  
2. **D2 南→北一次到位** — 糸満吃完再北上，別先北後南。  
3. **D3 本部半島內循環** — 美ら海→瀬底，不跨島南下。  
4. **D4 名護漁港→古宇利** — 同「東側／北側」半日。  
5. **高速用 ETC** — 連假收費站排隊很痛；那覇→許田省約 30–40 分。  
6. **還車預留塞車** — 4/7 南部回機場常塞。

預約：[Times](https://rental.timescar.jp/)｜Toyota｜Nippon｜ORIX｜比較站 web-rentacar

## 打包清單（和錢有關）

1. **駕照：** 台灣駕照＋日文譯本（或國際駕照依規定）。  
2. **ETC：** 自備或跟車行租。  
3. **現金：** 漁市場很多店偏現金（泊／糸満／名護）。  
4. **保險：** 旅平險＋租車免責。  
5. **行李：** 4 大箱 → 訂車時備註「スーツケース 4 個、3 列收納」。
