# Shinjuku Activities & Experiences

Shopping-first list for a **Feb 2027 one-day Shinjuku stop** on a Yuzawa ski trip. Focus is department stores, electronics, drugstores, and **outdoor/ski gear** you can actually use in Niigata, plus **two easy indoor/outdoor sights** that fit between shops.

**February note:** daylight is short; Shinjuku Gyoen last entry is typically **16:00** (closes 16:30) and the garden is **closed Mondays**. Cherry blossoms are not out — expect bare trees, possible late-month ume. Prioritize indoor malls if it snows or rains in Tokyo. Tax-free usually kicks in around **¥5,000 before tax** (passport same day).

**Sources:** LIVE JAPAN Shinjuku shopping map (Feb 2025) & “15 must-visit stores”; NAVITIME department-store guide; GOOD LUCK TRIP (Alpen, L-Breath); Tokyo Cheapo / Ishii Sports official; TimeOut Tokyo area copy; JATRABRIDGE Isetan + Gyoen itinerary.

## Suggested walking loops (pick one)

**East Exit (fashion + sweets + garden)**  
Isetan 10:00 → Matsukiyo 3-chome → Takano parfait → optional Gyoen (enter by 15:00) → BicCamera or Lumine Est → HARBS/BERG.

**West Exit (electronics + ski kit + izakaya)**  
Yodobashi + Ishii Sports → Alpen TOKYO (or skip if Ishii covered you) → free Tocho deck → Omoide Yokocho dinner (Tachan / Yasubee) → Nagi if still hungry.

**South Exit (one-building efficiency)**  
NEWoMan Blue Bottle → Takashimaya / HANDS → Katsukura 14F → L-Breath. Best if bags stay in a station locker and you are catching a late highway bus or Shinkansen from Shinjuku.

**Do not try all three loops in one day.** Two department stores + one electronics + one drugstore + one gear shop is already a full Feb day.
