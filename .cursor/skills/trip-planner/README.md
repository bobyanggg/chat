# trip-planner

From [skywain/trip-planner-skill](https://github.com/skywain/trip-planner-skill) (MIT), adapted for Cursor.

Vendored: playbook, references, scripts, Japan samples, theme renderers.
Not vendored: `themes/assets/` picture library and other country demos.

HTML output uses `scripts/render_plan.py`.

```
/trip-planner Japan, 12-15 days in October from London, mid budget, history and food
```

Natural language also works: "plan me 12 days in Japan".
